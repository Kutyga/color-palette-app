# Функциональность и дорожная карта

## Базовые функции (запрос)

1. **Моя коллекция** — растения с фото, видом, локацией (комната/окно/балкон), горшком, заметками.
2. **Отслеживание полива** — журнал, график, напоминания, экран «Сегодня».
3. **Чужие коллекции** — профили, подписки, лента, лайки, комментарии, настройки приватности.
4. **База знаний** — каталог видов с поиском, карточки ухода, статьи, болезни и вредители.
5. **Рекомендации по уходу** — персональные, с учётом вида, сезона, горшка, освещения и погоды.

## Что ещё можно добавить

### Уход и полезность
- **Распознавание растения по фото** — сразу подставляет вид и график ухода.
- **Диагностика болезней** — фото больного листа или мастер «жёлтые листья / пятна / вредители» →
  вероятные причины и план лечения.
- **Полный уход, не только полив** — удобрение, опрыскивание, пересадка, обрезка, поворот к свету,
  обработка от вредителей.
- **Умная подстройка графика** — по сезону, погоде (для балкона/сада), материалу горшка и тому,
  когда пользователь реально поливает.
- **Фото-дневник и таймлапс роста** — регулярные фото одного ракурса с «призраком» прошлого снимка,
  автосборка видео роста.
- **Замер освещённости** — люксметр через камеру/датчик телефона: «этому месту подходит …».
- **Размножение** — отслеживание черенков, «родословная» растения (от кого черенок).
- **Совместный уход** — семья или соседи по квартире ведут одни растения; «Уезжаю в отпуск» —
  передать уход другу со списком инструкций.
- **Виджеты рабочего стола и Apple Watch / Wear OS** — «сегодня полить 3», отметка в один тап.
- **Умные датчики** — интеграция с датчиками влажности почвы (Xiaomi Flower Care и т. п. по BLE).

### Социальное и сообщество
- **Обмен черенками / маркетплейс** — объявления «отдам/обменяю» с фильтром по городу.
- **Вопросы экспертам и сообществу** — пост-вопрос с фото, лучший ответ.
- **Челленджи и достижения** — «30 дней без пропусков», «10 видов суккулентов», бейджи.
- **Вишлист** — растения, которые хочу; друзья видят его (подсказка для подарков).
- **Публичная веб-страница коллекции** для шаринга ссылкой.

### Знания и контент
- **Совместимость с животными** — фильтр «безопасно для кошек/собак», предупреждения.
- **Подбор растения** — квиз: освещённость, время на уход, животные → список подходящих видов.
- **Сезонные советы** — «Октябрь: сократите полив, прекратите подкормку».
- **Календарь посадок** для дачников (по климатической зоне).

### Монетизация (при необходимости)
- Freemium: бесплатно до N растений и M распознаваний в день; **Premium** — безлимит, диагностика,
  таймлапс, датчики, расширенная статистика, без рекламы.
- Партнёрские ссылки на грунт, удобрения, горшки прямо из рекомендаций ухода.

## Дорожная карта

| Этап | Срок (ориентир) | Состав |
|---|---|---|
| **MVP** | 2–3 мес. | Авторизация, коллекция, локации, фото, полив + локальные напоминания, экран «Сегодня», база знаний (~300 популярных видов), базовые рекомендации, офлайн-режим |
| **v1.1 — Социальное** | +1,5 мес. | Профили, приватность, подписки, лента, лайки, комментарии, жалобы и блокировки, push |
| **v1.2 — Умный уход** | +1,5 мес. | Распознавание по фото, все виды ухода, сезонная и погодная подстройка, виджеты |
| **v2.0** | далее | Диагностика болезней, совместный уход, таймлапс, обмен черенками, челленджи, Premium, датчики |

## Основные экраны MVP

1. Онбординг (город для климата, время напоминаний, разрешение на уведомления)
2. **Сегодня** — список «полить/удобрить», свайп «сделано», «отложить на день»
3. **Моя коллекция** — сетка растений, фильтр по локациям, статус (ок / скоро / просрочено)
4. **Карточка растения** — фото, вид, график, журнал ухода, рекомендации, фото-дневник
5. **Добавление растения** — фото → (распознавание) → выбор вида → локация и горшок → готово
6. **База знаний** — поиск, категории, карточка вида
7. **Профиль и настройки**

Навигация — нижняя панель: *Сегодня · Коллекция · (+) · Лента · Знания*.
