# Дизайн «Подоконник»

Цель: приложение, которое открывают каждый день за 10 секунд («что полить?») и в которое
хочется возвращаться просто посмотреть на растения — свои и чужие.

## Что берём у лучших

| Источник | Приём | Где у нас |
|---|---|---|
| **apple.com / iOS** | Крупная жирная типографика (Large Title), много воздуха, контент вместо декора, один главный CTA на экран, «стеклянные» полупрозрачные панели, пружинные анимации | Все экраны: крупные заголовки, карточки с крупным фото, кнопка «Полить» на всю ширину, размытая нижняя навигация |
| **Apple Fitness / Health** | Кольца прогресса — мгновенно читаемый итог дня | «Сегодня»: кольцо «сделано N из M», цвета колец = виды ухода |
| **Instagram** | Ряд «историй» с цветным кольцом; профиль-сетка 3×N; двойной тап — лайк; центральная кнопка «+» | Ряд растений, которым нужен уход (кольцо = статус), коллекция сеткой, лента |
| **TikTok** | Полноэкранная вертикальная лента со «снапом», вкладки «Подписки / Интересное» | Рассматривали и отказались — см. «Сообщество» ниже |
| **Apple Mail / Things** | Действие прямо в строке списка, мгновенный отклик | Кнопка ✓ в строке задачи «Сегодня», подтверждение во всплывающем сообщении |

## Принципы

1. **Сначала растение, потом интерфейс.** Фото и название — самые крупные элементы. Хром (панели,
   рамки) минимален.
2. **Один тап до главного действия.** «Полить» доступно с экрана «Сегодня», из уведомления, из
   карточки растения.
3. **Статус считывается цветом без чтения.** Зелёный — всё хорошо, синий — скоро полив,
   коралловый — просрочено. Всегда дублируется текстом/иконкой (доступность).
4. **Спокойствие, а не тревога.** Никаких красных бейджей с числами; просрочка — мягкий
   коралловый, формулировки дружелюбные («Мося ждёт воды с понедельника»).
5. **Награда за заботу.** Кольцо замыкается, растение «оживает» анимацией, стрик дней.

### Типографика (системный шрифт: SF Pro на iOS, Roboto на Android)

| Стиль | Размер/вес | Пример |
|---|---|---|
| Large Title | 34 / Bold, трекинг −0.4 | «Сегодня» |
| Title | 22 / Semibold | Имя растения в карточке |
| Headline | 17 / Semibold | Заголовки секций |
| Body | 17 / Regular | Текст |
| Callout | 15 / Regular | Подписи в карточках |
| Caption | 13 / Medium | Мета-информация, чипы |

### Форма и ритм

- Сетка 4 px; поля экрана 16–20 px; промежутки между карточками 12 px.
- Скругления: 12 (чипы, поля), 20 (карточки), 28 (крупные карточки/листы), круг — аватары.
- Тени почти не используем — разделяем цветом поверхности (как iOS).
- Нижняя навигация — полупрозрачная с размытием (`backdrop-filter`, класс `.glass`), 5 пунктов:
  **Сегодня · Коллекция · (+) · Сообщество · Знания**; профиль — аватар в правом верхнем углу.

### Движение

- Плавные CSS-переходы 250–400 мс; листы (`Sheet`) выезжают снизу.
- Замыкание кольца прогресса — анимация.
- Уважение к «Уменьшить движение»: при `prefers-reduced-motion: reduce` анимации отключены.

## Ключевые экраны

### «Сегодня» (главный)
```
Среда, 24 сентября                          (аватар)
Сегодня                                      ← Large Title
┌──────────────────────────────────────────┐
│  ◯◯  2 из 5 сделано                       │ ← кольца Fitness: полив / другой уход
│      Ещё 3 растения ждут заботы           │
└──────────────────────────────────────────┘
(◉Мося) (◉Щучка) (◉Фикус) ...                ← «истории»: кольцо = статус
Просрочено
┌─[💧]─ Монстера Мося ── ждёт с понедельника ─[✓]┐  ← ✓ = готово
Сегодня
┌─[💧]─ Щучка ─────────── полить ─────────────[✓]┐
Скоро
  Фикус · подкормка · пт
```

### «Коллекция» (как профиль Instagram)
Шапка: число растений / мест / дней заботы подряд; фильтр-чипы по местам; сетка 3 колонки с
квадратными фото, точка статуса в углу. Пустое состояние — большая иллюстрация и одна кнопка.

### Карточка растения (как страница продукта apple.com)
Большое фото (на компьютере — слева), рядом крупное имя и вид;
«плашки-факты» (Полить · Свет · Место — место меняется нажатием);
кнопка **«Полить»** на всю ширину; график ухода; журнал; советы из базы знаний.

### «Сообщество» (дневники и взаимопомощь)
Формат TikTok/Instagram отказались: приложению нужна польза, а не бесконечная прокрутка.
Вкладки «Дневники | Помощь | Новости». Дневник — спокойные карточки событий (бейдж события,
растение, вид → база знаний, фото 4:3, «Поддержать», комментарии, «Дневник растения» —
хронология одного растения). «Помощь» — список вопросов со статусом «Ждёт ответа / N ответов /
Решено»; страница вопроса с ответами, лучший ответ закреплён сверху.

### «Знания» (как apple.com)
Огромное поле поиска, под ним «витрина»: крупные карточки подборок («Безопасно для кошек»,
«Для тёмной квартиры», «Неубиваемые»), затем список видов. Карточка вида — факты крупно,
советы — короткими пунктами.

## Доступность

- Контраст текста ≥ 4.5:1, статус всегда дублируется иконкой/текстом.
- Масштаб шрифта браузера до 200% без обрезаний.
- Все интерактивные элементы ≥ 44×44 px, у кнопок-иконок — `aria-label` для экранных чтецов.
- Тёмная тема — полноценная, не инверсия (`prefers-color-scheme: dark`).
